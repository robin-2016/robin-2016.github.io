Palmier Pro：AI时代的Mac视频编辑器

摘要

Palmier Pro 是一款为 Mac 打造的 AI 视频编辑器，用纯 Swift 原生开发，目标是做出“给 AI 智能体用的 Premiere Pro”。它把时间线剪辑和生成式 AI 揉进了同一个工作界面：可以在剪辑轨道里直接调用 Seedance、Kling、Nano Banana Pro 等模型生成素材，也可以把 Claude Code、Codex、Cursor 等智能体通过 MCP 接入，让它们和你一起编辑同一个项目。项目由 YC S24 团队打造，上线以来更新极快，GitHub 仓库已经积累了超过 1.4 万星标。

核心优势

时间线即事实源：过去做 AI 视频常见的流程是“网页生成 → 下载到本地 → 导入时间线 → 替换素材 → 重新剪辑”，反复循环还要手动给几十个版本的素材文件改名。Palmier Pro 把生成和剪辑放进同一个项目文件里，剪辑时间线本身就是唯一的事实来源，不用再在多个工具和多份文件之间来回倒腾。

智能体原生集成：应用运行时会在本地暴露一个 MCP 服务，Claude Code、Codex、Cursor、Claude Desktop 都可以直接连上去操作同一个剪辑项目。近几个版本里，智能体被赋予了更完整的编辑工作流所有权——比如管理时间线标记、批量替换素材来源、在应用内直接同步社区技能（skill）库，把原本只能“单点执行”的操作串成更完整的流程。

功能迭代速度很快：过去一个多月官方几乎每周都有版本更新，陆续加上了时间线标记、字幕文件（SRT/WebVTT）导入、轨道级关键帧动画、文字模糊与描边效果、静音片段智能剔除（并保护误伤的关键词）等剪辑能力；早期版本欠缺的转场、蒙版等功能，从最新的更新日志看也在逐步补齐。

开源边界发生了变化：这是与几个月前相比最大的不同——Palmier Pro 早期（v0.7.6 及之前）的二进制发行版和对应源码都以 GPLv3 协议开源；但从更新的版本开始，官方把二进制发行切换成了不可修改、不可再分发的专有许可，仓库也不再接受外部代码贡献，只保留历史源码（last-gpl-source 分支）供查阅和基于旧版本二次开发。也就是说，“核心剪辑功能完全开源”目前只适用于早期版本，不再是这个项目现在的准确描述。

面向人群

  • 需要频繁“生成素材 + 精细剪辑”往返迭代的 AI 视频创作者
  • 已经在用 Claude Code / Codex / Cursor 等智能体写脚本、做内容策划，想把生成视频也纳入同一个工作流的开发者
  • 想要一款免费、原生、无需订阅也能用的 Mac 视频剪辑软件的用户
  • 对早期 GPLv3 版本感兴趣、愿意基于历史开源分支自行二次开发的极客用户（注意仓库目前不再接受新的代码贡献）

使用方法

下载安装：Palmier Pro 面向 macOS 26（Tahoe）及以上的 Apple Silicon 设备，从项目仓库下载即可安装使用，无需登录、无需订阅即可作为普通视频剪辑软件使用。

接入 Claude Code：

claude mcp add --transport http palmier-pro http://127.0.0.1:19789/mcp

接入 Codex：

codex mcp add palmier-pro --url http://127.0.0.1:19789/mcp

接入 Cursor：应用内 Help → MCP Instructions → Install in Cursor 一键安装，或手动在 ~/.cursor/mcp.json 中加入对应配置。

接入 Claude Desktop：应用内 Help → MCP Instructions → Install in Claude Desktop，通过内置的桌面扩展包一键安装。

接入完成后，就可以直接让智能体读脚本、生成分镜素材、调整时间线，比如“用 Claude 写好脚本和分镜，再让它在 Palmier Pro 里按分镜生成对应片段”，或者把音效库之类的其他 MCP 服务和 Palmier Pro 一起接进同一个对话，实现跨工具协同。

常用编辑操作（不接智能体、在应用里手动操作也能用）：

  • 导入字幕：把 SRT/WebVTT 字幕文件拖进时间线即可生成字幕片段，也可以用内置转录先生成一份草稿再手动校对。
  • 打时间线标记：在播放头位置打标记方便跳转和分工协作；剪辑时插入或删除片段，标记会跟着时间线自动偏移，不用手动重新对位。
  • 智能去除静音：对素材运行“移除静音”会自动裁掉长静音片段，同时可以指定需要保留的关键词，避免误伤转录文本里的重要停顿。
  • 关键帧动画：给音量、文字大小、模糊度等属性打关键帧曲线，做出渐入渐出、缩放强调之类的效果。
  • 同步智能体技能：在 Help → 技能管理里可以直接拉取和更新社区维护的技能（skill），不用手动写 prompt 就能扩展智能体的编辑能力。

进阶用法

如果只用应用内置对话，AI 模型目前仅支持 Anthropic 系列；但通过外部 MCP 客户端接入后，就可以按需切换到其他模型供应商。生成式 AI 功能本身也在持续扩展——从最初的 Seedance、Kling、Nano Banana Pro，到之后陆续加入的 GPT-image-2.5、FLUX.3 视频生成工作流，以及用 MiniMax H3 做视频参考重构图（Edit → Reframe）等新能力。编辑、导出、连接智能体这些核心操作依旧免费、无需登录，只有调用生成式 AI 模型出片时才需要登录并订阅。

需要特别说明许可协议的变化：Palmier Pro 通过 v0.7.6（含）为止的二进制发行和对应源码采用 GPLv3 协议开源；从更新的版本开始，二进制发行改为专有许可，不允许复制、修改、再分发或反向工程，仓库本身也不再接受新的代码贡献，只保留历史开源分支供参考和基于旧版本继续开发。这也是这款产品上线几个月来最大的一次路线调整——从“完全开源、邀请社区共建”转向了更传统的商业软件许可模式。项目社区讨论可以在 Discord 和 GitHub Issues 里找到，也能通过 Twitter/X 关注更新。
