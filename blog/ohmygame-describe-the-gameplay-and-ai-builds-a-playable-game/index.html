OhMyGame：描述玩法，AI 帮你做出能玩的游戏

描述玩法，智能体替你做到浏览器里能玩。

摘要

OhMyGame 是一个开源的 AI 游戏工作室：你描述游戏，智能体负责设计文档、美术、代码和试玩自测，最后发布成一个任何人都能打开的链接。自带模型密钥，没有按次计费的额度。

核心优势

  • 智能体包办全流程。 先起草设计文档，再写代码，在实时预览里跑游戏，自己试玩，出了问题会尝试修复。
  • 一块画布放所有素材。 图片、视频、3D 模型、动画、配音、音效、音乐都能用 AI 生成，集中摆在同一块画布上，不用在五个软件之间来回切。
  • 发布成链接。 别人在浏览器里直接玩，作品还会出现在官方社区。多人游戏的房间，以及玩家的登录、存档、排行榜，发布时一并带上。
  • 插件可扩展。 插件能给智能体加技能、加工具，也能给应用加面板和项目类型。预装插件覆盖 Godot、Unity、Unreal Engine、Blender、Aseprite、Tiled，以及绿泡泡小游戏、抖某音小游戏等平台。
  • 自带智能体。 可以跑在 Claude Code、Codex、OpenCode 上，也可以接 40 多家模型服务商，用你自己的密钥。反过来也行：通过 MCP，在你自己的智能体里调用它的画布、媒体生成和试玩能力。

面向人群

  • 想一个人做完一款游戏、没有美术和程序搭档的独立开发者
  • 想快速验证玩法点子、需要先做出能玩原型的策划
  • 已经在用 Claude Code 等编程智能体，想让它接上游戏素材生成能力的人
  • 做互动小说、视觉小说、互动影像的创作者

能做什么游戏

官方给出的分类有三类：

类型 说明
Web 游戏 基于 Phaser、Three.js、React Three Fiber，官方建议从这里入手
互动故事 视觉小说、互动影像、剧情游戏
通用游戏 不限引擎和技术栈

Web 游戏还能做成多人：棋牌、实时对战竞技场都行，和朋友在线玩，不用自己搭服务器。

团队自己用它做了三个样例：一部互动影像、一个造岛游戏、一个卡牌构筑类 Roguelike。

快速上手

方式一：下载桌面应用。 目前提供 macOS（Apple 芯片）和 Windows（x64）版本。Windows 版还没有代码签名，首次安装时 SmartScreen 可能会弹警告。Intel 版 Mac 和 Linux 在路线图上。

方式二：从源码运行。 需要 Bun 1.4.2 以上和 Node.js 22.19 以上：

git clone https://github.com/WhiteTowerAI/ohmygame.git
cd ohmygame
bun install --frozen-lockfile
bun run dev            # 网页渲染端 + 本地守护进程
bun run dev:desktop    # 或者跑 Electron 桌面应用

从源码构建的版本不发送任何遥测数据。

首次启动要接模型。 OhMyGame 自己不带模型，第一次打开时，连接一个模型服务商，或者你已经在用的编程智能体即可。

隐私与注意事项

  • 项目和 API 密钥留在你自己的机器上，提示词直接发给你选的服务商。
  • 只有发布作品时才需要注册账号。
  • 正式发行版会上报使用数据和崩溃报告，可以在「设置 → 关于」里关掉。
  • 项目还在 beta 阶段，官方明说会有毛边，欢迎反馈问题。
  • 代码采用 Apache-2.0 协议，但 OhMyGame 的名称和 Logo 不在授权范围内。

上手清单

  1. 先装桌面应用，或用 Bun 从源码跑起来
  2. 首次启动接入一个模型服务商或本机已有的编程智能体
  3. 第一个项目选 Web 游戏，这是官方推荐的起点
  4. 用一两句话描述玩法，让智能体出设计文档，再看实时预览
  5. 满意后发布成链接，发给朋友试玩
