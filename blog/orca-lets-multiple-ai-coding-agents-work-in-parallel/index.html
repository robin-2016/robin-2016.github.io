AI Agent开发工具

Orca让多个AI编程智能体并行工作

摘要

Orca 是一款面向“百倍效率开发者”的 AI 编排工具（ADE），核心思路是让 Claude Code、Codex、OpenCode、Pi 等任意命令行 AI 编程智能体在各自独立的 Git worktree 中并行运行，并集中在一个界面里管理。它不锁定某一家模型厂商，而是用你已有的订阅去调度你已经在用的智能体，桌面端、移动端和远程 VPS 三端协同，让“一次提问、多个智能体同时干活、挑最好的结果合并”成为日常工作流。

核心优势

  • 智能体无关，即插即用：只要能在终端里跑起来的 CLI 智能体，理论上都能接入 Orca，官方列出的兼容列表已经覆盖了 Claude Code、Codex、Grok、Cursor、GitHub Copilot、OpenCode 等二十多种工具，用户不需要为了并行开发而绑定单一供应商。
  • 并行 Worktree 而非并行分支冲突：worktree 是 Orca 的基本任务单位，可以让多个智能体拿着同一提示词“赛马”同一个任务、再挑最优方案合并，也可以给不同 worktree 分配完全不同的任务甚至挂载不同智能体（比如一个改后端、一个改前端），实现真正的分工协作；每个智能体都在独立的 Git worktree 里工作，互不干扰，从根本上避免了多进程共享同一工作区带来的文件冲突。
  • 移动端实时掌控：配套的 iOS/Android 客户端可以远程查看智能体的运行状态，任务完成时推送通知，随时随地追加指令，把“等电脑跑完”变成“手机上继续指挥”。
  • 内置浏览器与 Design Mode：在真实的 Chromium 窗口里点选任意网页元素,就能把对应的 HTML、CSS 和裁剪截图直接塞进智能体的提示词,省去手动描述界面细节的麻烦。
  • 原生集成 GitHub 与 Linear：可以在应用内直接浏览 PR、Issue 和项目看板，从任意任务一键开出新的 worktree，评审代码时无需切换上下文；配合逐行批注 AI Diff 的能力，评审、修改、提交可以在同一个界面内形成闭环。
  • SSH 远程 Worktree：把繁重的智能体任务丢到一台配置更高的远程服务器上运行，依然拥有完整的文件编辑、Git 操作和终端体验，并支持断线自动重连和端口转发。
  • CLI 可编程：Orca 自身也提供命令行接口（orca worktree create、snapshot、click、fill 等），意味着智能体不仅是被调度的对象，也可以反过来驱动 Orca，把整套工作流脚本化。

面向人群

  • 需要同时驱动多个 AI 编程智能体、对比不同方案效果的开发者
  • 已经在为 Claude Code、Codex 等工具付费，不想再额外购买聚合平台订阅的用户
  • 团队协作中需要把 PR review、任务分派、AI 辅助编码整合到同一界面的工程师
  • 希望通过手机随时查看和干预远程编码任务进度的移动办公场景

快速上手

macOS（Homebrew）：

brew install --cask stablyai/orca/orca

Arch Linux（AUR）：

yay -S stably-orca-bin
# 或从源码构建：yay -S stably-orca-git

也可以直接从 onOrca.dev 或 GitHub Releases 下载对应平台的安装包：macOS（Apple Silicon / Intel）、Windows（.exe）、Linux（AppImage）。

安装完成后：

  1. 打开 Orca，登录已有的智能体账号（如 Claude Code、Codex），无需重新注册订阅。
  2. 打开一个 Git 仓库，为要处理的任务创建 worktree。
  3. 输入一次提示词，选择要并行派发的智能体数量，Orca 会自动在多个独立 worktree 中同时启动它们。
  4. 智能体运行完成后，在界面中对比各自的 diff，逐行添加批注或直接合并满意的结果。

如果要在无图形界面的 Linux 服务器上运行，可以执行 orca serve 并参考官方的 headless 部署指南。

进阶用法

  • 移动端跟进：iOS 端可从 App Store 或 TestFlight 安装，Android 端可直接下载 APK，配合桌面端使用即可在通勤路上继续跟进智能体的执行进度。
  • Design Mode 联动前端调试：在内置浏览器里点选页面元素，自动生成的 HTML/CSS/截图会作为上下文注入到下一次提示中，特别适合“改这个按钮的样式”这类视觉相关的任务。
  • 账号与用量管理：内置账号切换器可以查看 Claude、Codex 等智能体的用量和限流重置时间，并在多个账号间无缝切换，避免手动重新登录。
  • 脚本化编排：借助 Orca CLI 把 worktree 创建、快照、UI 操作等步骤写成脚本，让智能体本身也能调用 Orca 完成更复杂的自动化任务链。
  • 远程算力扩展：通过 SSH worktree 把资源消耗大的任务放到远程主机执行，本地只保留一个轻量的控制端。

Orca 目前以 MIT 协议开源，更新节奏很快，官方建议关注 GitHub Releases 页面获取最新的功能列表，日常反馈和功能请求可以直接在仓库的 Issues 中提出。
